Component CSS Extractor 追加テスト

このファイルを Chrome で直接開いてください。サーバーや通信は不要です。各テストでは指定した枠内の要素を右クリックして「検証」を選びます。

1. 変換できない外側の条件と警告

下の「テスト対象 1」の div.state-target を選択します。CSS Extractor は「Elementsで選択」「選択要素のみ」、ルートのクラス名は state-result にして解析してください。

テスト対象 1：親要素にマウスが載ると赤くなる

期待結果：.theme:hover .state-target は元のまま残り、HTML には state-target が残ります。「選択範囲外の要素・状態に依存します」という警告に、このセレクタが表示されます。親の状態条件を消した .state-result:hover にはなりません。

2. 別オリジンの CSS

外部 CSS 専用のテストページを開いてください。サーバーは不要ですが、この項目だけはインターネット接続が必要です。実際の CSS 補完と、補完できない場合の警告の模擬を試せます。

3. 「両方コピー」した結果の再現

下の「テスト対象 3」の div.copy-sample を選択します。「Elementsで選択」「選択要素のみ」、ルートのクラス名は copy-result にして解析し、パネルの「両方コピー」を押してください。

テスト対象 3：青い文字と余白をコピー

期待結果：プレビューでも文字が青く、余白が付きます。出力 HTML に元の copy-sample や外側の copy-shell は不要です。この貼り付け欄は、上の単一の div を「両方コピー」した形式を対象としています。

4. CSS を含める設定の切り替え

下の「テスト対象 4」の div.toggle-base を選択します。「Elementsで選択」「選択要素のみ」、ルートのクラス名は toggle-result にします。

テスト対象 4：設定を切り替えて再解析
  1. @media と「疑似クラス」をオンにして解析すると、border-radius、@media (min-width: 1px) 内の letter-spacing、.toggle-result:hover の色が出ます。
  2. @media をオフにして再解析すると、letter-spacing だけが消えます。
  3. 「疑似クラス」もオフにして再解析すると、.toggle-result:hover も消え、border-radius は残ります。
