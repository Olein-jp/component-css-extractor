Component CSS Extractor 機能テスト

この HTML ファイルを Chrome で直接開いてください。サーバーは不要です。DevTools の Elements パネルで指定の要素を選び、CSS Extractor パネルで解析します。

1. 先ほどの修正：外側の親クラスを除いた出力

  1. 下の「テスト対象 1」を右クリックして「検証」を選びます。青い文字の div.fixture-sample が選択対象です。
  2. CSS Extractor で「Elementsで選択」、範囲は「選択要素のみ」、ルートのクラス名は component-test にして解析します。
テスト対象 1：この青い文字の div を選択

期待結果：HTML は class="component-test" と data-state="ready" を持ちます。CSS に .component-test[data-state="ready"] の色、通常の余白、@media (min-width: 700px) 内の余白が出ます。.fixture-shell > .fixture-sample は残らず、外側への依存を示す警告も出ません。余白が上下左右に分かれて表示されても正常です。

2. クラスを入力して解析

  1. CSS Extractor で「クラスを入力」を選び、クラス名欄に manual-pad manual-strong と入力します。Elements パネルでの要素選択は不要です。
  2. ルートのクラス名を manual-result にして解析します。

期待結果：CSS に .manual-result の padding と font-weight: 700 が出ます。手入力では元の HTML がないため、HTML 欄が空なのは正常です。

3. 子要素を含めて解析

  1. 下の薄い青色のカード全体を右クリックして「検証」を選び、Elements パネルで div.fixture-card-pad が選ばれていることを確認します。
  2. CSS Extractor で「Elementsで選択」、範囲は「子孫要素を含む」、ルートのクラス名は card-demo、セレクタ方式は「コンポーネントクラスを生成」にして解析します。

テスト対象 3：カードの見出し

カードの説明文です。

期待結果：HTML に card-demo、card-demo__title、card-demo__description が付きます。CSS では親の余白と背景色、見出しの文字サイズと太さ、説明文の文字色が別々のセレクタで出ます。「選択要素のみ」に切り替えると、子要素の CSS は出ません。
