CSS Cascade 調査用ページ

この HTML ファイルを Chrome で直接開けます。各点線枠の要素を Elements パネルで選択し、CSS Extractor の「選択要素のみ」、ルートクラス component-test で解析してください。

1. レイヤーの順序

青い文字。元 CSS では first より second が優先されます。

期待結果：抽出 CSS の先頭に @layer first, second; があり、second と first のブロックが続きます。その CSS を別ページに貼っても青い表示を再現できます。

2. :where() 内の状態

普段は青、マウスを載せると赤い文字。

期待結果：マウスを載せていない状態で解析しても、通常時の青いルールと .where-target:where(:hover) の赤いルールが出力されます。生成 HTML には where-target が残り、コピー先でもホバーすると赤くなります。

3. インラインスタイル

赤い文字。CSS ルールは青、style 属性は赤。

現行の抽出 CSS は青いルールだけです。HTML と CSS を両方コピーすれば style 属性が残るため赤を再現できますが、CSS だけを別の HTML に使うと青になります。

4. 選択範囲外からの継承

紫で太字の文字。色は親要素から継承しています。

期待結果：抽出CSSには font-weight: 700 だけが含まれ、紫色が選択範囲外の親要素から継承されている旨の警告が表示されます。計算済みの紫色はCSSへ固定値として追加されません。
