Component CSS Extractor @layer テスト

この HTML ファイルを Chrome で直接開いてください。サーバーやインターネット接続は不要です。拡張を再ビルドした場合は、chrome://extensions で拡張を再読み込みし、DevTools も開き直してください。

1. 通常のレイヤー順

  1. 下の青い要素を右クリックして「検証」を選びます。
  2. CSS Extractor を「Elementsで選択」「選択要素のみ」にします。
  3. ルートのクラス名を layer-normal-result にし、@layer をオンにして解析します。
  4. 「CSSをコピー」で結果を下の欄へ貼り付け、「貼り付けたCSSを表示」を押します。
テスト対象1：元ページでは青い文字

期待結果：CSS の先頭に @layer normal-first, normal-second を含む順序宣言があり、プレビューも青い文字になります。このページ内の別テスト用レイヤー名が同じ順序宣言に含まれていても正常です。

2. 複数スタイルシートと !important

  1. 下の赤い要素を右クリックして「検証」を選びます。
  2. 設定は「Elementsで選択」「選択要素のみ」、ルートのクラス名は layer-important-result、@layer はオンにします。
  3. 解析した CSS を下の欄へ貼り付けて表示します。
テスト対象2：元ページでは赤い文字

期待結果：important-first が important-second より先に宣言され、両方の !important が残ります。重要宣言ではレイヤーの優先順位が反転するため、プレビューも赤い文字になります。

3. @layer を含めない設定

  1. テスト対象1または2を選択したまま、CSS Extractor の「@layer」をオフにします。
  2. もう一度解析します。

期待結果：抽出 CSS にレイヤーブロックも @layer …; の順序宣言も残りません。このページの対象要素はレイヤー内にしか CSS がないため、「一致するCSSがありません」と表示されても正常です。
